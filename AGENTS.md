# Risk the Loot Project Rules

- This project is in active playtest development.
- Prefer better gameplay, clearer systems, and simpler code over compatibility with old saves.
- Save migrations are optional. It is acceptable to bump the save key or reset test progress when a feature benefits from a cleaner data model.
- Keep equipped gear, loot risk, extraction, mobile controls, and readable combat feedback at the center of design decisions.
- Verify desktop and mobile layouts whenever interface controls or gear presentation change.
